# ОРБИТА — рабочее место аналитика ВКД

Исследовательский планировщик для КосмоХакатона. Локальный запуск включает data-pipeline v2: реальные источники, кэш, проверки качества, SGP4, replay и раздельную оценку механизмов. Статический сайт сохраняет демонстрационный режим.

Подробности, импорт архивов и ограничения моделей: [Data pipeline](docs/data-pipeline.md).

## Запуск

Требуется Node.js 20+.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Проверки: `npm test` и `npm run check`.

## Сценарии

- Параметры ВКД: 1–8 часов, поиск сдвига вперёд до 24 часов с шагом 1 час.
- Таймлайн обстановки (окна, SEP у станции, шкала S на GOES, буря Hp30, ЮАА, сближения, уведомления DONKI/NCEI, освещённость, пробелы данных), все окна-кандидаты с местом в ранжировании, лучшие хорошие окна или два лучших доступных, объяснение выбора.
- Космическая погода и событийные предупреждения о сближениях. Сближения не подменяют модель всего фонового MMOD.
- Интерактивная карта, выбор окна, временного диапазона, масштаба и момента на траектории.
- Необязательное ограничение освещённости использует те же синтетические орбитальные отсчёты, что карта.
- Архивный разбор и Replay с отсечением по времени публикации. Поздние наблюдения доступны только в отдельной ретроспективной сверке.
- Отключение источников, пересчёт статуса и уверенности, обновление данных.
- ZIP-экспорт: `calculation.json`, `sources.json`, `report.html`. HTML можно распечатать в PDF. Сохранённые расчёты хранятся локально в браузере (до 15 записей).

## Архитектура и подключение API

`dist/providers.js` — точка получения данных. `MockDataProvider` и `ApiDataProvider` предоставляют одинаковый `calculate(request, disabledSources)` и возвращают `{ plan, data }`. Локальный сервер подключает `/v2/eva/dataset` автоматически. [Контракт v2](docs/api-contract-v2.md) развязывает источники и факторы; [v1](docs/api-contract.md) сохранён для демо. При ошибке API нет скрытого переключения на фейковые данные.

`pipeline/` содержит загрузчики, файловый кэш, QA, построение профиля и Python worker IGRF/AP-8. `dist/pipeline.js` оценивает окна вектором, `dist/pipeline-view.js` показывает покрытие и причины неопределённости. Настраиваемые пороги — `data/rules.json`. Python-зависимости опциональны; инструкции установки приведены в документации пайплайна.

`dist/domain.js` — чистая логика оценки без DOM. `dist/app.js` — представления и взаимодействия. `dist/export.js` — автономный ZIP-экспорт. `dist/styles.css` — адаптивный интерфейс. `dist/assets/world.json` — локальная подложка карты.

## Границы прототипа

Это не инструмент допуска к реальной ВКД. В API используются реальные данные и SGP4, но правила остаются исследовательскими. Уверенность v2 качественная, с причинами. Решают механизмы с порогами (SEP, захваченные частицы, метеороиды); ГКЛ и сближения — контекст. SEP оценивается по справочнику «Внешние опасности»: дипольное обрезание, ослабление CARI-7A в бурю, оценки сверху там, где спектр GOES заканчивается, и базовый прогноз «последнее наблюдение сохраняется» для будущих часов. Метеорный поток — фон Грюна с границей из выпусков NASA MEO. Для полного исторического профиля нужен импорт OMM Space-Track и архива GOES (`pipeline/goes_history.py`). SpacePy 0.7.0 с PyPI содержит IGRF-13 (до 2025.0): для текущих дат на сервере ставится `requirements-server.txt` с IGRF-14, подробности — в [Data pipeline](docs/data-pipeline.md). Полная строгая воспроизводимость не заявляется. В статическом демо значения и траектория синтетические.

## Деплой

Сайт — статический ES-module frontend. Для обычного хостинга достаточно содержимого `dist/`, сборка не нужна.

Для GitHub Pages подготовлена папка `docs/`. После загрузки репозитория на GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, затем ветку `main` и папку `/docs`, после чего нажмите **Save**. GitHub покажет ссылку на опубликованный сайт на той же странице.

Все данные будущего API передаются через HTTPS; CORS разрешает origin фронтенда. Секреты в `config.js` не размещать.

## Географическая подложка

Упрощённые границы из [datasets/geo-countries](https://github.com/datasets/geo-countries), основаны на Natural Earth; исходные географические данные public domain. Это географическая визуализация, а не оперативный источник положения МКС.
