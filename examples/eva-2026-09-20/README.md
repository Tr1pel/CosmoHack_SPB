# Пример сохранённого расчёта

Это ZIP-экспорт из интерфейса «Сохранить расчёт» за 20 сентября 2026 года.

- `calculation.json` — полный расчёт, включая профиль и план;
- `sources.json` — источники, версии и статусы;
- `report.html` — автономный отчёт, который можно открыть в браузере или распечатать в PDF.

Файлы служат примером формата выгрузки, а не эталонной научной верификацией.
